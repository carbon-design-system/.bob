# .bob

Shared IBM Bob configuration files for Carbon squads including modes, rules, skills, commands, and more.

## Getting started

1. Clone this directly into your root bob folder, `~/.bob`, or clone elsewhere and reference or symlink everything to `~/.bob`
2. Periodically pull from `main` to get updates
3. Open a pull request if you make something useful that other squads would benefit from

> [!NOTE]  
> If you have files already in `~/.bob`, you can clone to a different directory and then symlink individual files to the appropriate directory
> ```sh
> ln -s /your/path/commands/cve-research.md ~/.bob/commands/cve-research.md
> ```
